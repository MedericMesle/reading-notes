# Reading notes

Books I'm working through, with notes in my own words, exercise answers, and what I apply at work.

## How it works

1. **Read with a mission** — each book is picked for a problem I'm facing now.
2. **One note per chapter** — key ideas, exercises, where it applies, one action.
3. **Apply** — every chapter ends with something concrete to try.
4. **Debrief** — a short retro when the book is done.

Progress is tracked with one GitHub issue per chapter, closed by the commit that finishes it.
